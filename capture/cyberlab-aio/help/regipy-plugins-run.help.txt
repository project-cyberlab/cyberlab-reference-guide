Usage: regipy-plugins-run [OPTIONS] HIVE_PATH

Options:
  -o FILE                       Output path for plugins result  [required]
  -p, --plugins TEXT            A plugin or list of plugins to execute command
                                separated
  -t, --hive-type TEXT          Specify a hive type, if it could not be
                                identified for some reason
  -r, --partial_hive_path TEXT  The path from which the partial hive actually

                                starting from HKCU/Software
  -v, --verbose                 Verbosity
  --include-unvalidated         Include plugins that don't have validation

                                incomplete or inaccurate data. Use at your own
                                risk.
