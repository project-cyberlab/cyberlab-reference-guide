usage: floss [-h] [-H] [-n MIN_LENGTH]
             [--no {static,stack,tight,decoded} [{static,stack,tight,decoded} ...]]
             [--only {static,stack,tight,decoded} [{static,stack,tight,decoded} ...]]
             [-j] [-v] [-d] [-q] [--color {auto,always,never}]
             sample

The FLARE team's open-source tool to extract ALL strings from malware.
  floss 3.1.1 - https://github.com/mandiant/flare-floss/

FLOSS extracts the following string types:
 1. static strings:  "regular" ASCII and UTF-16LE strings
 2. stack strings:   strings constructed on the stack at run-time
 3. tight strings:   special form of stack strings, decoded on the stack
 4. decoded strings: strings decoded in a function

Language-specific strings:
 1. Go:   strings from binaries written in Go
 2. Rust: strings from binaries written in Rust

positional arguments:
  sample                path to sample to analyze

options:
  -h, --help            show this help message and exit
  -H                    show advanced options and exit
  -n MIN_LENGTH, --minimum-length MIN_LENGTH
                        minimum string length

analysis arguments:
  --no {static,stack,tight,decoded} [{static,stack,tight,decoded} ...]
                        do not extract specified string type(s)
  --only {static,stack,tight,decoded} [{static,stack,tight,decoded} ...]
                        only extract specified string type(s)

rendering arguments:
  -j, --json            emit JSON instead of text
  -v, --verbose         enable verbose results, e.g. including function
                        offsets (does not affect JSON output)

logging arguments:
  -d, --debug           enable debugging output on STDERR, specify multiple
                        times to increase verbosity
  -q, --quiet           disable all status output on STDOUT except fatal
                        errors
  --color {auto,always,never}
                        enable ANSI color codes in results, default: only
                        during interactive session

only displaying core arguments, run `floss -H` to see all supported options

examples:
  extract all strings from an executable
    floss suspicious.exe

  do not extract static strings
    floss --no static -- suspicious.exe

  only extract stack and tight strings
    floss --only stack tight -- suspicious.exe
